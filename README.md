# SmartFLO VOC 접수 채널

SmartFLO 사용 중 발견하신 이슈, 불편 사항, 개선 제안을 체계적으로 접수하기 위한 채널입니다.  
작성해주신 내용은 개발팀에서 검토하여 순차적으로 반영합니다.

---

> [!WARNING]
> ## ⚠️ 사내 정보 작성 금지
>
> 이 채널은 **Public(공개) 저장소**입니다. 아래 정보는 절대 작성하지 마세요.
>
> - 고객사명, 사업명, 계약 관련 내용
> - 보안 등급 정보, 내부 시스템 접속 정보
> - 팀 내부 인원 실명, 연락처
>
> 부득이하게 언급이 필요한 경우 **'H사', 'A프로젝트'** 등 가명으로 처리해 주세요.

---

## 사용 방법

1. 상단 **Issues** 탭을 클릭합니다.
2. 우측 상단 **New issue** 버튼을 클릭합니다.
3. **VOC / 개선 요청** 양식을 선택하여 작성 후 제출합니다.

> GitHub 계정이 없으신 경우, 개인 이메일로 5분 내 가입 가능합니다 (회사 정보 불필요).

---

## 처리 흐름

| 단계 | 내용 |
|------|------|
| 접수 | 양식 제출 즉시 자동 등록 |
| 1차 회신 | **24~48시간** 내 검토 후 코멘트로 회신 |
| 반영 일정 | 우선순위에 따라 개발 일정 공유 |
